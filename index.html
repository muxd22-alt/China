    10GbE switch — needed?

    Yes, for inference first: RPC KV/tensor traffic between Node A↔B strangles at 110 MB/s on 1 GbE. Also carries PXE multicast and the NAS fabric. NICs are ¥110.

    Copy one OS to 100GB NVMe ×6?

    Golden image → Clonezilla SE PXE multicast: install once (CachyOS + RADV + BC-250 governor), serve from the core host, flash all node drives in ~3 min/batch. Re-config = re-clone, never re-install.

    2TB + NAS storage?

    3×2TB NVMe (VM/models + a dedicated game library + KV/agent scratch) + two 8TB mirror pairs: media/Jellyfin/cameras and games/backups — 16TB usable, ZFS-fault-tolerant.

    Replace the high-end core PC?

    Yes — the 7900X+X670E+DDR5+3090 tower (¥10.6K) is cancelled. Heavy lifting moves to the boards (~81GB model pool, gaming + Sunshine encode); ¥3,430 of cheap AM4 does storage/VMs/PXE. The 3090 waits at optional P3.

    Why 2 + 4 boards?

    Node A keeps one 14B–32B orchestrator resident (~28GB); Node B runs 3 workers (~41GB) plus a flex board that flips to game duty — inference never drops below 2+3 while someone plays.

    Redundancy?

    Hot-swap 1+1 PSU · boards are ¥750 commodities + golden re-clone · ZFS mirrors · new ATX PSU (never used) · UPS for core+network.
